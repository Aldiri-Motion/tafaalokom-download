# تطبيق تفاعلكم — تنزيل

تطبيق أندرويد لتصميم كوفرات تفاعلكم وتجهيز فيديوهات الريل، وبيشتغل بدون نت.

## التنزيل

**[⬇ نزّل آخر نسخة](https://github.com/Aldiri-Motion/tafaalokom-download/releases/latest/download/tafaalokom.apk)**

## التثبيت

1. افتح الرابط فوق من التلفون ونزّل الملف.
2. افتح الملف واضغط **تثبيت**. إذا طلب «السماح من هذا المصدر» اسمحله.
3. النسخ الجديدة بتنزل فوق القديمة بدون ما ينمسح شغلك.

بيشتغل على أندرويد 7 وأحدث.
